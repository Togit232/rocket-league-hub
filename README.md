# Rocket League Hub

Inoffizielles Fan-Dashboard für Rocket League: RLCS-Ergebnisse, Turniere, Rankings, Team-Kader, News und Patch Notes.

- **Lokal (Live-Daten):** `python3 server.py --open` – benötigt nur Python 3.
- **Online:** `.github/workflows/update.yml` baut etwa alle 30 Minuten einen Daten-Schnappschuss und veröffentlicht ihn auf GitHub Pages.

Datenquellen: Liquipedia (CC-BY-SA 3.0), BLAST.tv, Steam, Reddit, SHIFT. Kein offizielles Produkt von Psyonix, Epic Games oder BLAST.
